# Paths that must never be committed (AGENTS.md rule 1: no real financial data).
#
# This is the single source of truth for the guard (scripts/guard_paths.py), which runs as a
# pre-commit hook on staged files and in CI over every file a PR adds or changes. Keep it in step
# with the "Known export file patterns" section of .gitignore (that file stops accidental
# `git add`; this one also stops `git add -f`).
#
# Syntax, one pattern per line; blank lines and '#' comments are ignored; matching is
# case-insensitive and uses forward slashes:
#   dir/        any path with that directory as a component, at any depth
#   *.ext       glob matched against the file name (no '/' in the pattern)
#   a/b*.csv    glob matched against the whole path from the repo root (has a '/')
#   /dir/       leading '/' anchors to the repo root
#   !pattern    re-allows what an earlier line blocked (the last matching line wins)
#
# If a synthetic fixture needs a name that matches, prefer renaming it (e.g. sample_export_01.csv)
# over adding an allow line.
